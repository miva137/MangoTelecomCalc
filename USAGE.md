# Инструкция по использованию калькулятора тарифов

Калькулятор сравнивает тарифы ВАТС и КЦ Манго Телеком и считает стоимость в месяц и разовые платежи.

## Запуск

Откройте файл `tariff-compare.html` в браузере. Для работы нужны файлы `script.js` и `styles.css` в той же папке.

## Режимы работы

Выберите режим в поле «Режим»:

- **Сравнение тарифов** - сравнивается текущий тариф с новым. В таблице видна разница в руб./мес.
- **Расчет тарифа** - показывается только один тариф. Колонка «Разово, руб.» отображает разовые платежи.

## Выбор продукта и тарифов

1. В поле «Продукт» выберите **ВАТС** или **КЦ**. При смене продукта все выбранные функции, номера и профили сбрасываются.
2. В поле «Текущий тариф» выберите тариф, который используется сейчас.
3. В поле «Новый тариф» выберите тариф для сравнения (в режиме расчета поле скрыто).

## Добавление функций ВАТС

1. В поле «Услуга» начните вводить название. Появится список подсказок; выберите нужный пункт мышью или стрелками и нажмите Enter.
2. Нажмите «Добавить в сравнение».
3. Чтобы убрать функцию, нажмите «×» на плашке над таблицей или в строке таблицы.

По умолчанию добавлены «Безлимитная запись разговоров», «Интеграция Битрикс24 / amoCRM», «Облачное хранилище» и «Пакет на связь».

Дополнительно в поиске доступны:

- **Номера** - «Номер в коде 499», «Номер в коде 495», «Мобильные номера». Количество вводится прямо в строке таблицы.
- **Доп. профили сотрудников** - количество вводится в строке таблицы.
- **Манго Диалоги** - базовая стоимость и количество доп. каналов вводятся в строке таблицы.

## Настройка строк таблицы

- **Облачное хранилище** - в строке выбирается объем (1 ГБ или 5 ГБ), цена меняется автоматически.
- **Пакет на связь** - в строке выбирается пакет из списка.
- **Скидка** - в колонках «Скидка текущего, %» и «Скидка нового, %» введите процент от 0 до 100. Скидка пересчитывает только суммы в руб./мес.

Ограничения:

- Скидка недоступна для мобильных номеров.
- Для функции «Интеграция Битрикс24 / amoCRM» скидка не применяется, если выбран базовый тариф.

## Номера и превышение лимита

- Под таблицей показывается предупреждение, если количество номеров превышает лимит тарифа или включенное количество.
- Номера сверх включенного количества оплачиваются по тарифу. Стоимость такого номера указана в строке.

## Итоги

- Строка «Итого в месяц» показывает сумму для текущего и нового тарифа и разницу. Рост суммы выделяется красным, снижение - зеленым.
- Суммы учитывают только значения в руб./мес.; разовые платежи указаны отдельно.

## Блок КЦ

1. Установите флажок «Добавить КЦ» (доступен только для ВАТС).
2. Появится отдельный блок с выбором текущего и нового тарифа КЦ.
3. Добавьте функции КЦ через поле «Услуги КЦ» и кнопку «Добавить в сравнение».
4. Внизу блока показаны итоги КЦ и итоги ВАТС + КЦ.
