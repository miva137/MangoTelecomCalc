# Инструкция по использованию калькулятора тарифов

Калькулятор рассчитывает стоимость тарифов ВАТС и КЦ Манго Телеком, сравнивает два тарифа и показывает экономию или удорожание.

## Запуск

1. Откройте `tariff-compare.html` в современном браузере.
2. Не перемещайте отдельно файлы `script.js` и `styles.css`: они должны находиться рядом с HTML-файлом.
3. Для шрифтов Google Fonts требуется интернет. Без доступа к нему калькулятор использует системные шрифты.

## Режим и продукт

В поле **«Режим»** выберите:

- **«Сравнение тарифов»** — текущий и новый тарифы рассчитываются рядом, а в колонке «Разница» показывается изменение стоимости.
- **«Расчет тарифа»** — рассчитывается один выбранный тариф. Поле нового тарифа скрывается; для номеров появляется отдельная колонка «Разово, руб.».

В поле **«Продукт»** выберите основной расчёт:

- **ВАТС**: Базовая, Расширенная, Максимальная, Старт, Рост, Перспектива.
- **КЦ**: Оптимум, Профи, Корпорация.

При смене продукта выбранные услуги и количественные параметры сбрасываются. Затем выберите тариф или пару тарифов в верхних выпадающих списках.

## Добавление и удаление услуг

1. В поле **«Услуга»** начните вводить название.
2. Выберите подходящий вариант мышью либо клавишами `↑`/`↓` и `Enter`.
3. Нажмите **«Добавить в сравнение»**. Нажатие `Enter` в поле поиска также добавляет выбранную услугу.
4. Удалите услугу кнопкой **×** на плашке над таблицей.

Для ВАТС изначально выбраны безлимитная запись разговоров, интеграция Битрикс24 / amoCRM, облачное хранилище и пакет на связь. При выборе тарифов Старт, Рост или Перспектива дополнительно используется один профиль сотрудника.

Для КЦ по умолчанию добавлена услуга «Доп.лицензия». Ее количество можно изменить непосредственно в строке таблицы.

## Настройка строк

В таблице можно:

- включить или выключить строку для каждого тарифа флажком **«Учитывать в сравнении»**;
- указать скидку отдельно для текущего и нового тарифа в процентах;
- выбрать объём облачного хранилища отдельно для каждого тарифа;
- выбрать пакет на связь;
- ввести количество городских номеров 499, 495, мобильных номеров и дополнительных профилей;
- задать количество дополнительных каналов «Манго Диалоги»;
- удалить ненужную добавленную функцию через плашку или ввести ей нулевое количество.

Переключатель **«Показать скидки»** скрывает или возвращает столбцы скидок. Само скрытие столбцов не отменяет уже заданные скидки.

Скидка применяется только к денежной стоимости соответствующей строки в рублях в месяц. Для мобильных номеров скидка недоступна. Для интеграции Битрикс24 / amoCRM скидка не применяется на тарифе Базовая. Доплата за номера сверх лимита также не уменьшается скидкой.

## Номера и лимиты

Через поиск можно добавить:

- виртуальный городской номер 499;
- виртуальный городской номер 495;
- виртуальный мобильный номер.

Для них рассчитываются ежемесячная и разовая стоимость. Действуют следующие правила:

- **Базовая** — не более 3 номеров.
- **Расширенная** — не более 15 номеров.
- **Максимальная** — 15 номеров включены, далее 150 руб./мес. за каждый номер.
- **Старт** — не более 5 номеров.
- **Рост** — 10 номеров включены; с 11-го по 30-й номер доплата 150 руб./мес.
- **Перспектива** — без ограничения количества и без доплаты за превышение.

При превышении лимита или включённого количества калькулятор показывает предупреждение под таблицей.

## Совместный расчёт ВАТС и КЦ

Расчёт можно выполнить двумя способами:

- выберите продукт **КЦ**, чтобы работать только с услугами контакт-центра;
- при основном продукте **ВАТС** включите **«Добавить КЦ»**, чтобы открыть дополнительный блок контакт-центра.

В блоке КЦ выберите тарифы, добавьте услуги через поиск и настройте количество лицензий, включение строк и скидки. В режиме сравнения отображаются отдельный итог КЦ и общий итог ВАТС + КЦ для обеих сторон сравнения. В режиме расчёта одного тарифа второй тариф КЦ не используется.

## Итоги и обозначения

- **«Итого в месяц»** учитывает только значения с единицей `руб./мес.`.
- Разовые платежи не входят в месячный итог. В режиме одного тарифа они показаны отдельно в колонке **«Разово, руб.»**.
- Положительная разница и рост стоимости выделяются красным со знаком `+`.
- Снижение стоимости выделяется зелёным.
- `✓` или `+` означает функцию, включённую без отдельной платы; в расчёте она равна нулю рублей.
- `—` означает отсутствие функции или недоступность ее для тарифа.
- Значения с поминутной, посекундной или иной тарификацией не превращаются автоматически в прогноз ежемесячной стоимости, если для них нет количества и суммы в `руб./мес.`.

Перед использованием итога проверьте тарифы, количество номеров и профилей, выбранные услуги, скидки и флажки «Учитывать в сравнении».
