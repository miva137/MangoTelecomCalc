# Калькулятор сравнения тарифов Манго Телеком

Одностраничный калькулятор для расчёта и сравнения стоимости тарифов ВАТС и КЦ. Работает без сборки и серверов: достаточно открыть HTML-файл в браузере.

## Информация о релизе

### Release 1.0.0

- **Дата выпуска:** 19.11.2026
- **Владелец:** Манго Телеком
- **Тип продукта:** Одностраничный калькулятор тарифов ВАТС и КЦ
- **Формат поставки:** Статические файлы HTML, CSS и JavaScript
- **Среда выполнения:** Современный настольный или мобильный браузер
- **Архитектура:** Без сервера, сборки, базы данных и внешнего API

### Назначение релиза

Релиз предназначен для расчёта стоимости тарифа ВАТС или КЦ и для сравнения текущего и нового тарифов в одном рабочем интерфейсе. Инструмент помогает учитывать ежемесячную стоимость услуг, индивидуальные скидки, разовые платежи, номера и лимиты тарифов.

### Состав релиза

- режим «Сравнение тарифов» с отображением стоимости и разницы;
- режим «Расчет тарифа» с расчётом одного выбранного тарифа;
- тарифы ВАТС: Базовая, Расширенная, Максимальная, Старт, Рост и Перспектива;
- тарифы КЦ: Оптимум, Профи и Корпорация;
- выбор дополнительных услуг ВАТС и КЦ с подсказками;
- расчёт номеров, дополнительных профилей и служебных услуг;
- настройка скидок для текущего и нового тарифа;
- отдельные итоги по ВАТС, КЦ и суммарный итог;
- предупреждения о превышении лимитов и включённых номеров;
- серый разворачиваемый блок сведений о релизе внизу страницы.

### Пользовательские сценарии

1. Пользователь выбирает режим работы и продукт: ВАТС или КЦ.
2. Для ВАТС можно одновременно добавить и КЦ флажком «Добавить КЦ».
3. Выбираются текущий и новый тарифы, а для расчётных строк задаются параметры услуг.
4. При необходимости указываются процентные скидки каждого тарифа.
5. Таблица показывает месячную стоимость и разницу; режим расчёта дополнительно показывает разовые платежи.

### Ограничения релиза

- Итоговая сумма включает только значения в рублях в месяц.
- Разовые платежи в общую месячную сумму не входят.
- Мобильные номера рассчитываются без скидки.
- Скидка для «Интеграции Битрикс24 / amoCRM» не применяется к базовым тарифным условиям текущего тарифа.
- Для загрузки шрифтов Raleway и Roboto требуется доступ к Google Fonts; при недоступности шрифты заменяются системными.

### Технические сведения

Основная логика находится в `script.js`, визуальное оформление — в `styles.css`, разметка интерфейса и сведения о релизе — в `tariff-compare.html`. Данные тарифов и расчётные правила содержатся внутри приложения и загружаются при открытии страницы.

## Возможности

- Выбор продукта (ВАТС или КЦ), текущего и нового тарифа.
- Режим: «Сравнение тарифов» (текущий и новый тариф рядом с разницей) или «Расчет тарифа» (только текущий тариф, без сравнения). Правила расчёта одинаковые в обоих режимах; стоимость номеров и доп. профилей входит в итог тарифа.
- Поле функции: при нажатии или фокусе открывается полный список функций, при вводе текста список фильтруется по совпадению. Стрелками выбирается пункт, Enter добавляет функцию в сравнение, Escape закрывает список. Выбранные функции выводятся плашками и удаляются крестиком.
- Пакет на связь (300, 600, 2500, 10000 посекундный, 17000 посекундный руб./мес.) добавлен по умолчанию, удаляется крестиком. Скидка на пакет задаётся отдельно для текущего и нового тарифа.
- Таблица сравнения: цена текущего и нового тарифа, разница в руб./мес. Плюс (рост цены) выделяется красным, минус (снижение цены) - зелёным.
- В режиме «Расчет тарифа» отдельный столбец «Разово, руб.» показывает единоразовую плату за номера; в режиме сравнения он скрыт.
- Подключаемые номера (номер в коде 499, номер в коде 495, мобильные, доп. профили) с разовой и ежемесячной ценой.
- Строки таблиц выровнены по центру.
  - Базовый - лимит 3, Расширенный - 15, Старт - 5, доплаты нет. Сверх лимита выводится предупреждение.
  - Максимальный - 15 номеров без доплаты, лимита нет. Сверх 15 каждый номер дороже: мобильный 350, номер 499 - 400, номер 495 - 500 руб./мес.
  - Рост - 10 номеров без доплаты, с 11-го по 30-й номер такая же доплата, сверх 30 выводится предупреждение.
  - Перспектива - без ограничений и доплат.
- Надбавка за номер сверх лимита добавляется к стоимости номера после скидки и сама скидкой не уменьшается.
- Если номеров больше лимита тарифа, выводится предупреждение; при превышении включённых номеров выводится размер доплаты.
- Флажок «Добавить КЦ» открывает отдельную таблицу КЦ с суммой по выбранным услугам. Услуги КЦ выбираются в поле «Услуги КЦ» и выводятся плашками с оранжевой обводкой, как услуги ВАТС.
- Итоговая строка показывает сумму только по значениям в руб./мес.
- Скидка в процентах задаётся отдельно для каждой строки и для каждого тарифа (текущего и нового). Для мобильных номеров скидка не предусмотрена: поле скидки не выводится, стоимость считается без неё.
- Для функции «Интеграция Битрикс24 / amoCRM» скидка текущего тарифа не применяется, если текущий тариф Базовый. Скидка нового тарифа доступна, если он не Базовый.
- Облачное хранилище: одна строка таблицы, выбранная по умолчанию.

## Ограничения

- Расчёт учитывает только значения в руб./мес. Разовые платежи в итоговую сумму не входят.
