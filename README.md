# Калькулятор сравнения тарифов Манго Телеком

Калькулятор Манго Телеком помогает рассчитать ежемесячную стоимость услуг ВАТС и КЦ, сравнить текущий и новый тарифы или посчитать один тариф. Поддерживаются номера, профили, скидки, лимиты и экспорт результата. Приложение работает прямо в браузере без сборки, сервера и базы данных.

## Запуск

Откройте [Калькулятор тарифов](index.html) в современном браузере. Корневой файл `index.html` автоматически открывает основную страницу `tariff-compare.html`.

Сборка, сервер и база данных не требуются; структура файлов должна оставаться неизменной: JavaScript находится в `js/`, а стили — в `styles.css`.

Шрифты Raleway и Roboto загружаются из Google Fonts. Без доступа к интернету используются системные шрифты.

Для локального использования достаточно открыть `index.html`. Для GitHub Pages корневая страница также автоматически перенаправляет пользователя на калькулятор. Инструкция доступна из футера калькулятора и в [USAGE.md](USAGE.md).

## Режимы работы

- **Сравнение тарифов** — рядом показываются текущий и новый тарифы с разницей в рублях в месяц.
- **Расчет тарифа** — показывается стоимость одного тарифа. Для номеров дополнительно отображается колонка разовых платежей.

## Продукты и тарифы

В калькуляторе доступны два продукта:

- **ВАТС** — Базовая, Расширенная, Максимальная, Старт, Рост, Перспектива и Виртуальный номер.
- **КЦ** — Оптимум, Профи и Корпорация.

При смене продукта дополнительные услуги и пользовательские количественные параметры сбрасываются. Для тарифов Старт, Рост и Перспектива автоматически выбирается один дополнительный профиль сотрудника.

## Расчёт ВАТС

Поле «Услуга» поддерживает поиск подсказками, выбор стрелками и клавишей Enter, а выбранные услуги выводятся плашками над таблицей. Уже добавленные услуги и дополнительные позиции не показываются повторно в выпадающем списке. Функцию можно удалить кнопкой «×», а кнопка **«Очистить услуги»** удаляет пользовательский выбор и количества, восстанавливая набор услуг по умолчанию.

По умолчанию подключены:

- Безлимитная запись разговоров;
- Интеграция Битрикс24 / amoCRM;
- Облачное хранилище.

Дополнительно доступны пакеты на связь, виртуальные номера в кодах 499 и 495, мобильные номера, дополнительные профили сотрудников и Манго Диалоги.

Для каждой строки можно настроить участие в итоговом расчёте и скидки текущего и нового тарифа отдельно. Скидка применяется к ежемесячной стоимости. Переключатель **«Показать скидки»** скрывает или показывает поля скидок; при любом переключении введённые скидки сбрасываются и итог пересчитывается. Для мобильных номеров поле скидки не выводится.

## Расчёт КЦ

Флажок «Добавить КЦ» доступен в режиме ВАТС и открывает отдельный блок КЦ. Для КЦ выбираются текущий и новый тарифы, добавляются услуги и рассчитывается своя итоговая строка.

В режиме расчёта одного тарифа КЦ также доступен: он рассчитывается для одного тарифа, а поле нового тарифа скрывается. Для ВАТС-тарифа «Виртуальный номер» совместный расчёт с КЦ недоступен.

## Номера и лимиты

В строках учитываются включённые номера и дополнительные профили. При превышении лимита калькулятор выводит предупреждение и доплату за номера сверх лимита.

Основные правила:

- Базовая — лимит 3 номера.
- Расширенная — лимит 15 номеров.
- Старт — лимит 5 номеров без дополнительной оплаты сверх лимита.
- Максимальная — 15 номеров без доплаты, затем доплата за каждый дополнительный номер.
- Рост — 10 номеров без доплаты, с 11-го по 30-й номер взимается доплата.
- Перспектива — без ограничений и дополнительной платы.
- Виртуальный номер — один городской номер; мобильные номера и подключение КЦ недоступны.

Надбавка за номер сверх лимита добавляется после расчёта скидки на номер и сама скидкой не уменьшается. Для тарифов ВАТС 2 объём облачного хранилища включает базовую квоту; дополнительные 5-ГБ блоки рассчитываются отдельно.

## Итоги

Итоговая строка показывает ежемесячную стоимость текущего и нового тарифа. В режиме сравнения дополнительно выводится разница: рост выделяется красным, снижение — зелёным.

Разовые платежи в итог ВАТС и КЦ не входят. В режиме расчёта отдельная колонка «Разово, руб.» показывает разовую плату за номера.

При включённом КЦ итог КЦ и суммарный итог ВАТС + КЦ выводятся в блоке КЦ.

## Экспорт

Кнопка экспорта сохраняет только строки, участвующие хотя бы для одной стороны расчёта. Названия выбранных тарифов выводятся в заголовках стоимостных колонок; при совместном расчёте указываются тарифы ВАТС и КЦ. Результат можно скачать в CSV с разделителем `;` или в современном `.xlsx`-файле на основе OOXML. Для Excel применяются ширины колонок, перенос текста и отдельные стили заголовка и итоговой строки.

## Ограничения

**По тарифам и продуктам:**

- Итог учитывает только значения в рублях в месяц.
- Разовые платежи не входят в итоговую месячную сумму.
- Скидка недоступна для мобильных номеров.
- Скидка для «Интеграции Битрикс24 / amoCRM» не применяется к базовому тарифу ВАТС.
- Калькулятор поддерживает 7 тарифов ВАТС и 3 тарифа КЦ; добавление новых тарифов требует обновления базы данных в `js/tariff-data.js`.
- При смене продукта все выбранные услуги и пользовательские параметры сбрасываются.

**По номерам и лимитам:**

| Тариф | Лимит | Доплата за превышение |
|---|---|---|
| Базовая | 3 номера | Не доступна |
| Расширенная | 15 номеров | Не доступна |
| Максимальная | 15 вкл., далее доплата | 150 руб./мес. за номер |
| Старт | 5 номеров | Не доступна |
| Рост | 10 вкл., далее доплата | 150 руб./мес. за номер (11–30) |
| Перспектива | Без ограничений | Нет доплаты |
| Виртуальный номер | 1 городской номер | — |

- Мобильные номера не входят в лимит городских, но доплачиваются отдельно.
- Для тарифа «Виртуальный номер» подключение КЦ невозможно.
- Доплата за номера сверх лимита не подлежит скидке.

**По расчётам:**

- Значения с поминутной, посекундной или специальной тарификацией не преобразуются в месячный прогноз без указания количества и суммы в `руб./мес.`.
- При совместном расчёте ВАТС + КЦ скидки применяются независимо для каждого продукта.
- Преобразование курсов валют не поддерживается.
- Максимальная скидка ограничена 100%.

**По услугам и хранилищу:**

- Облачное хранилище рассчитывается блоками по 5 ГБ, дополнительные блоки приобретаются отдельно.
- На тарифах Старт, Рост и Перспектива базовый объём входит в стоимость.
- Дополнительные услуги загружаются из набора, определённого для каждого тарифа.

**По экспорту:**

- Экспортируются только строки, участвующие хотя бы для одного тарифа.
- CSV использует разделитель `;`.
- Excel-файл формируется в формате OOXML (`.xlsx`) с автоматическим форматированием.

Полный список ограничений и особенностей см. в разделе **«Ограничения и особенности калькулятора»** в [USAGE.md](USAGE.md).
