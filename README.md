# Калькулятор сравнения тарифов Манго Телеком

Одностраничный калькулятор для сравнения текущего и нового тарифа ВАТС, с опциональным блоком КЦ. Работает без сборки и серверов: достаточно открыть HTML-файл в браузере.

## Состав проекта

| Файл | Назначение |
| --- | --- |
| [tariff-compare.html](tariff-compare.html) | Разметка страницы и подключение скриптов и стилей |
| [styles.css](styles.css) | Стили в фирменной палитре Манго Телеком |
| [script.js](script.js) | Данные тарифов, расчёт итогов и логика интерфейса |
| [vats.sql](vats.sql) | SQL-таблица `vats_tariffs` и данные тарифов ВАТС |
| [kc.sql](kc.sql) | SQL-таблица `kc_tariffs` и данные тарифов КЦ |

## Запуск

1. Открыть [tariff-compare.html](tariff-compare.html) в браузере.
2. Для загрузки шрифтов Google нужен доступ в интернет. Без него страница работает со шрифтами по умолчанию.

## Возможности

- Выбор продукта (ВАТС или КЦ), текущего и нового тарифа.
- Режим: «Сравнение тарифов» (текущий и новый тариф рядом с разницей) или «Расчет тарифа» (только текущий тариф, без сравнения). Правила расчёта одинаковые в обоих режимах; стоимость номеров и доп. профилей входит в итог тарифа.
- Поле функции: при нажатии или фокусе открывается полный список функций, при вводе текста список фильтруется по совпадению. Стрелками выбирается пункт, Enter добавляет функцию в сравнение, Escape закрывает список. Выбранные функции выводятся плашками и удаляются крестиком.
- Пакет на связь (300, 600, 2500, 10000 посекундный, 17000 посекундный руб./мес.) добавлен по умолчанию, удаляется крестиком. Скидка на пакет задаётся отдельно для текущего и нового тарифа.
- Таблица сравнения: цена текущего и нового тарифа, разница в руб./мес. Плюс (рост цены) выделяется красным, минус (снижение цены) - зелёным.
- В режиме «Расчет тарифа» отдельный столбец «Разово, руб.» показывает единоразовую плату за номера; в режиме сравнения он скрыт.
- Подключаемые номера (номер в коде 499, номер в коде 495, мобильные, доп. профили) с разовой и ежемесячной ценой.
- Строки таблиц выровнены по центру.
- Лимит номеров на каждый тариф. При превышении выводится предупреждение и плата за лишние номера.
- Флажок «Добавить КЦ» открывает отдельную таблицу КЦ с суммой по выбранным функциям.
- Итоговая строка показывает сумму только по значениям в руб./мес.
- Скидка в процентах задаётся отдельно для каждой строки и для каждого тарифа (текущего и нового).
- Для функции «Интеграция Битрикс24 / amoCRM» скидка текущего тарифа не применяется, если текущий тариф Базовый. Скидка нового тарифа доступна, если он не Базовый.
- Облачное хранилище: выбор объёма (1 ГБ — 190 руб./мес., 5 ГБ — 490 руб./мес.). Цена строки меняется в зависимости от объёма. Варианты задаются в `STORAGE_PLANS` в [script.js](script.js).

## Данные

Цены и функции хранятся в константе `DATA` в [script.js](script.js). Структура:

- `DATA.vats` и `DATA.kc` содержат список `rows`.
- Каждая строка имеет поля `parameter` (название) и `values` (значение по каждому тарифу).

Таблицы из SQL-файлов повторяют эти данные и нужны для загрузки в базу. Их нужно обновлять вместе с `DATA`.

## Обновление цен

1. Изменить значения в [vats.sql](vats.sql) или [kc.sql](kc.sql).
2. Перенести изменения в `DATA` в [script.js](script.js).
3. Открыть страницу и проверить итоги.

## Ограничения

- Расчёт учитывает только значения в руб./мес. Разовые платежи в итоговую сумму не входят.
- Нет серверной части: данные хранятся только в коде страницы.
